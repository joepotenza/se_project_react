# WTWR: What to Wear

WTWR is a React.js application for deciding what to wear based on the weather. It uses the openweathermap.org API to get weather data. It allows for user registration, and utilizes the browser's geolocation data to determine the user's location for weather reports.

## Technologies Used

- HTML5
- CSS3
- React.js
- Vite
- Geolocation support
- Flexbox and grid layout
- Responsive design

## Back-End

The Back-End API code, written in Node.js and Express, can be found at [https://github.com/joepotenza/se_project_express](https://github.com/joepotenza/se_project_express)
