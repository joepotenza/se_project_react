# WTWR: What to Wear

WTWR is a React.js application for deciding what to wear based on the weather. It uses the openweathermap.org API to get weather data. It allows for user registration, and utilizes the browser's GeoLocation to determine the user's location for weather reports.

## Technologies Used

- HTML5
- CSS3
- React.js
- Geolocation support
- Flexbox and grid layout
- Responsive design
